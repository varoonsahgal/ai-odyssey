Vertex AI → Gemini Enterprise Agent Platform

In April 2026, Google introduced Gemini Enterprise Agent Platform as "the evolution of Vertex AI". Vertex AI services and their roadmap now ship through the Agent Platform. Expect to see both names for a while: blog posts and older docs say Vertex AI, while API hostnames, IAM roles and SDK packages keep aiplatform.

New governance pieces (2026)

Agent Identity (agents get their own principals), Agent Registry (a catalog of agents and skills), Agent Gateway (a policy-enforced entry point), Agent Sandbox (isolated code execution) and Model Armor (prompt and response screening). Optimization tools: Agent Simulation, Agent Observability, Agent Optimizer.

Cheat sheet

google-genai (Gemini SDK)

from google import genai
from google.genai import types
from pydantic import BaseModel

client = genai.Client(vertexai=True, project=PROJECT_ID, location="global")

# 1 · Plain call with a system instruction and thinking level
r = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="Explain gradient boosting to a pirate.",
    config=types.GenerateContentConfig(
        system_instruction="You are concise.",
        thinking_config=types.ThinkingConfig(thinking_level="low"),
        temperature=0.7),
)
print(r.text, r.usage_metadata)

# 2 · Structured output
class Ticket(BaseModel):
    category: str
    urgency: int
r = client.models.generate_content(model="gemini-3.8-flash", contents="My order never arrived!!",
    config=types.GenerateContentConfig(response_mime_type="application/json", response_schema=Ticket))
ticket = r.parsed

# 3 · Multimodal from Cloud Storage
r = client.models.generate_content(model="gemini-3.8-flash", contents=[
    types.Part.from_uri(file_uri="gs://bucket/video.mp4", mime_type="video/mp4"),
    "List key moments with timestamps."])

# 4 · Tools: Python function (auto-called) + Google Search grounding
def get_order_status(order_id: str) -> dict:
    """Look up the shipping status of an order."""
    return {"order_id": order_id, "status": "Shipped"}
r = client.models.generate_content(model="gemini-3.8-flash", contents="Where is order 42?",
    config=types.GenerateContentConfig(tools=[get_order_status]))
r = client.models.generate_content(model="gemini-3.8-flash", contents="Latest TPU announcement?",
    config=types.GenerateContentConfig(tools=[types.Tool(google_search=types.GoogleSearch())]))

# 5 · Streaming, chat, tokens, embeddings
for chunk in client.models.generate_content_stream(model="gemini-3.8-flash", contents="Count to 5"):
    print(chunk.text, end="")
chat = client.chats.create(model="gemini-3.8-flash"); chat.send_message("Hi!")
client.models.count_tokens(model="gemini-3.8-flash", contents="How many tokens am I?")
client.models.embed_content(model="gemini-embedding-001", contents=["hello", "world"])

from google.cloud import aiplatform
aiplatform.init(project=PROJECT_ID, location="us-central1",
                staging_bucket=BUCKET, experiment="odyssey")

# Experiments
aiplatform.start_run("run-1"); aiplatform.log_params({"lr": 0.1}); aiplatform.log_metrics({"auc": 0.84}); aiplatform.end_run()

# Custom training job
job = aiplatform.CustomJob.from_local_script(display_name="train", script_path="train.py",
        container_uri="us-docker.pkg.dev/vertex-ai/training/xgboost-cpu.2-1:latest")
job.run()

# Registry → endpoint
model = aiplatform.Model.upload(display_name="churn", artifact_uri=f"{BUCKET}/model",
        serving_container_image_uri="us-docker.pkg.dev/vertex-ai/prediction/xgboost-cpu.2-1:latest")
endpoint = model.deploy(machine_type="n2-standard-4", min_replica_count=1, max_replica_count=3)
endpoint.predict(instances=[[...]])
endpoint.undeploy_all()          # ← stop paying!

# Pipelines
aiplatform.PipelineJob(display_name="p", template_path="pipeline.yaml",
                       pipeline_root=f"{BUCKET}/pipeline_root").submit()

-- Train / evaluate / predict / explain
CREATE OR REPLACE MODEL ds.m OPTIONS(model_type='BOOSTED_TREE_CLASSIFIER', input_label_cols=['y']) AS SELECT ...;
SELECT * FROM ML.EVALUATE(MODEL ds.m);
SELECT * FROM ML.PREDICT(MODEL ds.m, (SELECT ...));
SELECT * FROM ML.EXPLAIN_PREDICT(MODEL ds.m, (SELECT ...), STRUCT(3 AS top_k_features));
SELECT * FROM ML.GLOBAL_EXPLAIN(MODEL ds.m);

-- Time series
CREATE MODEL ds.f OPTIONS(model_type='ARIMA_PLUS', time_series_timestamp_col='t', time_series_data_col='v') AS SELECT ...;
SELECT * FROM ML.FORECAST(MODEL ds.f, STRUCT(30 AS horizon));
SELECT * FROM AI.FORECAST(TABLE ds.series, data_col => 'v', timestamp_col => 't', horizon => 30);  -- TimesFM, zero-shot

-- Unsupervised
CREATE MODEL ds.k OPTIONS(model_type='KMEANS', num_clusters=5) AS SELECT ...;
SELECT * FROM ML.DETECT_ANOMALIES(MODEL ds.f, STRUCT(0.95 AS anomaly_prob_threshold));

SELECT AI.GENERATE(('Summarize: ', review_text), connection_id => 'us.odyssey_conn', endpoint => 'gemini-3.8-flash').result FROM ...;
SELECT * FROM VECTOR_SEARCH(TABLE ds.items, 'embedding', (SELECT embedding FROM ds.query), top_k => 5);

🔌 MCP: tools for agents

Model Context Protocol. An agent connects to an MCP server to discover and call tools such as databases, APIs and files. Think USB-C for tools.

🤝 A2A: agents talking to agents

Agent2Agent protocol (v1.0). Agents publish an agent card and delegate tasks to each other across teams, frameworks and clouds. Think HTTP for agents.

🧹 Full cleanup

Read before running

This deletes everything the course created. Only run it in your course project, never in a shared one.

REGION=us-central1
# Undeploy + delete endpoints
for E in $(gcloud ai endpoints list --region=$REGION --format="value(name)"); do
  gcloud ai endpoints undeploy-model $E --region=$REGION --deployed-model-id=$(gcloud ai endpoints describe $E --region=$REGION --format="value(deployedModels[0].id)") --quiet 2>/dev/null
  gcloud ai endpoints delete $E --region=$REGION --quiet
done
# Cloud Run services (incl. GPU)
for S in $(gcloud run services list --region=$REGION --format="value(metadata.name)"); do
  gcloud run services delete $S --region=$REGION --quiet; done
# BigQuery datasets
for D in odyssey_d1 odyssey_d2 odyssey_d3 odyssey_d4 odyssey_d5; do bq rm -r -f -d "$PROJECT_ID:$D"; done
# Bucket
gcloud storage rm -r "gs://$PROJECT_ID-odyssey"
# Or simply: gcloud projects delete $PROJECT_ID   (the cleanest of all)

Also delete in the Console: Agent Runtime instances, RAG corpora, vector indexes, Feature Store online stores and tuned-model endpoints.

Meta-skill

API drift survival guide

  1. Read the error literally. "Unexpected keyword argument" means the API was renamed. Check the signature with help(fn).
  2. Pin and print versions. Run pip show google-genai google-adk google-cloud-aiplatform and include the output in every bug report.
  3. Inspect objects. dir(obj), obj.model_dump() and df.columns beat guessing.
  4. Check the model ID first. Most 404s are retired models.
  5. Go to the source. The SDKs are open source on GitHub, and their samples are always current.
  6. Ask Gemini with context. Paste the error plus your installed version.
Glossary

Words of the voyage

A2AAgent2Agent protocol for inter-agent communication via agent cards and tasks.
ADCApplication Default Credentials. Libraries find your identity automatically.
ADKAgent Development Kit, Google's open-source agent framework (Python, Go, Java, TS, Kotlin).
Agent RuntimeManaged hosting for agents, with sessions, memory and sandboxed execution.
ARIMA_PLUSBQML's decomposition + ARIMA forecaster with holidays and anomaly handling.
AutoraterAn LLM used as a judge to score outputs against a rubric.
Context cachingReuse a large prompt prefix across calls at reduced cost and latency.
DriftChange in input (feature) or output (prediction) distributions over time.
EmbeddingA vector representation where semantic similarity becomes geometric closeness.
GroundingAnchoring model output to verifiable sources (Search, your data) with citations.
KFPKubeflow Pipelines SDK v2, the language of Agent Platform Pipelines.
MCPModel Context Protocol, the standard way to expose tools and data to models and agents.
Memory BankLong-term, per-user memory for agents that persists across sessions.
Model ArmorA service that screens prompts and responses for injection, jailbreaks, PII and harmful content.
RAGRetrieval-augmented generation: fetch relevant context, then generate.
SFTSupervised fine-tuning on input→output examples.
SynthIDGoogle's imperceptible watermark for AI-generated media.
Thinking levelHow much internal reasoning a Gemini model spends before answering (LOW/MEDIUM/HIGH).
TimesFMGoogle's foundation model for time-series forecasting, available via AI.FORECAST.
vLLMA high-throughput open-source LLM serving engine with an OpenAI-compatible API.

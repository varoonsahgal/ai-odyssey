State of the cosmos · November 2026

The map changed. A lot.

If your mental model of Google Cloud AI is from 2024, this course is your recalibration. These are the changes the labs are built around.

Rebrand

Vertex AI → Gemini Enterprise Agent Platform

Since April 2026, Vertex AI services are delivered through the Agent Platform. It covers models, training, pipelines, agents and governance in one place. The old names still show up in SDKs and docs, and we'll decode both.

Models

Gemini 4 + 3.8 Flash

gemini-4-argon handles frontier "deep work" with a 1M-token context and LOW/MEDIUM/HIGH thinking levels. gemini-3.8-flash and gemini-3.5-flash-lite are the workhorses. Gemini 2.5 retired in October 2026.

Agents

ADK 2.0 + Agent Runtime

ADK 2.0 adds a graph-based engine that mixes model-led reasoning with deterministic workflows. Agents deploy to Agent Runtime with Sessions, Memory Bank and Sandbox, and they talk to each other over A2A.

Creative

Nano Banana & Omni

Image generation and editing now run on Gemini-native models (gemini-3.1-flash-image, gemini-3-pro-image). gemini-omni-1.2-flash is the successor to the Veo line for video.

Governance

Agent Identity, Gateway & Model Armor

Agents get their own identities, a registry and a gateway. Model Armor screens prompts and responses for injection, jailbreaks and data leakage, and Day 5 is about breaking past it.

Data + AI

BigQuery is an AI engine

AI.GENERATE, AI.FORECAST with TimesFM, vector search, and BigQuery DataFrames. Classical ML and generative AI now meet in SQL, and Day 1 starts there.

Philosophy

Classical roots, frontier branches

Not every problem needs a trillion-parameter model. A churn model in BigQuery ML costs pennies, trains in minutes and is fully explainable. An agent that reads contracts needs Gemini. Senior AI engineers know which tool fits which job, and this course teaches that judgment.

  • Days 1–2 build the discipline: features, metrics, pipelines, monitoring.
  • Days 3–4 unleash generative AI and agents on top of that foundation.
  • Day 5 closes the loop: tune, evaluate, secure and run it at scale.

You'll see the same e-commerce dataset (thelook_ecommerce) come back across the week. Day 1 predicts churn on it, Day 3 writes retention emails, Day 4 builds the support agent and Day 5 evaluates and defends it.

How the expedition runs

Learn → Build → Battle → Debrief

Each day follows the same rhythm, tuned for energy and retention. Short concept bursts, long lab blocks, one dramatic finale.

🛰️

Briefing

20–30 min concept bursts with diagrams, the "why" and how it works under the hood. No 2-hour slide marathons.

🧪

Labs

Step-by-step missions with copy-ready code, expected outputs, hints and stretch goals. Tick off steps to earn XP.

☠️

Boss battle

An open-ended end-of-day challenge that combines everything. Teams race, and the boss HP bar drops as you hit criteria.

📡

Debrief

A quick quiz, a show-and-tell, and a "what would break in prod?" discussion before the next world.

Who should board

This course is for you if…

  • You write Python comfortably and can read SQL.
  • You know the basics of ML: train/test split, overfitting, precision vs. recall.
  • You've used some cloud (any provider) and aren't scared of a terminal.
  • You want to go from "I called an LLM API once" to "I run AI systems in production."

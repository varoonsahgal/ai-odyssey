Before you arrive

What you need on the launch pad

  • A Google Cloud project with billing enabled. Budget about $40–80 for the full week if you follow the cleanup steps. Day 5's GPU and tuning labs are the biggest line items.
  • Permissions: Owner on a sandbox project is easiest. In locked-down orgs, see the role list in step 5 below.
  • A browser. Cloud Shell and Colab Enterprise mean zero local installs. Prefer local? You'll need Python 3.12+ and the gcloud CLI.
  • Optional: a GitHub account (Day 2 CI/CD) and a Hugging Face account with accepted Gemma license (Day 5).

Cadet, a word of advice from the old-timers: the most common way to lose an hour this week is a missing API or an org policy blocking a service account. Do this prep the day before class, not during. Mission Control out.

For instructors

Classroom setup options

Recommended

One project per learner

Cleanest isolation, simplest IAM (each learner is Owner) and a clear per-person cost. Create projects from a folder with a budget per project.

OK

One project per team

Teams of 2–3 share a project. Prefix every resource with the team name (odyssey_d1_teamorion). Watch quotas on shared endpoints.

Hard mode

Shared class project

Possible, but per-learner datasets, buckets and service accounts get messy, and one runaway GPU job hurts everyone. Avoid unless forced.

LAB 0.1 · PRE-FLIGHT

Ignition Sequence

⏱ 45 min★☆☆☆☆+100 XP🧰 Cloud Shell · gcloud · Colab Enterprise

Configure a project that's ready for every lab in the course, with cost guardrails from minute one.

  1. Open Cloud Shell and set your coordinates

    Click the >_ icon in the Cloud Console header. Then:

    export PROJECT_ID="your-project-id"        # ← change me
export REGION="us-central1"
export BUCKET="gs://${PROJECT_ID}-odyssey"

gcloud config set project "$PROJECT_ID"
gcloud config set compute/region "$REGION"

# Persist for future Cloud Shell sessions
cat >> ~/.bashrc <<EOF
export PROJECT_ID="$PROJECT_ID"
export REGION="$REGION"
export BUCKET="$BUCKET"
EOF

  2. Enable the APIs for the whole week

    gcloud services enable \
  aiplatform.googleapis.com \
  bigquery.googleapis.com \
  bigqueryconnection.googleapis.com \
  bigquerystorage.googleapis.com \
  storage.googleapis.com \
  compute.googleapis.com \
  dataform.googleapis.com \
  notebooks.googleapis.com \
  cloudbuild.googleapis.com \
  artifactregistry.googleapis.com \
  run.googleapis.com \
  secretmanager.googleapis.com \
  modelarmor.googleapis.com \
  cloudtrace.googleapis.com \
  monitoring.googleapis.com \
  logging.googleapis.com \
  iam.googleapis.com \
  cloudresourcemanager.googleapis.com \
  billingbudgets.googleapis.com
    Why still "aiplatform"?

    Gemini Enterprise Agent Platform (the April 2026 evolution of Vertex AI) is served from the same aiplatform.googleapis.com API. The brand changed but the endpoints and IAM roles kept their names. See the rename decoder.

    "Operation finished successfully." This can take 1–2 minutes.
    Why does a course about AI need the Cloud Build, Secret Manager and Cloud Trace APIs?

    Because AI in production is mostly software engineering. Cloud Build ships your pipelines on Day 2, Secret Manager holds the Hugging Face token on Day 5, and Cloud Trace shows you why an agent was slow on Days 4–5.

  3. Install a budget alarm before spending a cent

    BILLING_ACCOUNT=$(gcloud billing projects describe "$PROJECT_ID" \
  --format="value(billingAccountName)" | sed 's|billingAccounts/||')

gcloud billing budgets create \
  --billing-account="$BILLING_ACCOUNT" \
  --display-name="AI Odyssey guardrail" \
  --budget-amount=100USD \
  --filter-projects="projects/$PROJECT_ID" \
  --threshold-rule=percent=0.5 \
  --threshold-rule=percent=0.9 \
  --threshold-rule=percent=1.0
    Budgets alert, they don't stop

    A budget sends email at each threshold but does not cap spend. Your real protection is the daily cleanup at the end of each day page. Undeploy endpoints, delete Cloud Run GPU services, and stop notebooks.

    Permission denied on billing?

    You need roles/billing.costsManager on the billing account. Ask your instructor or admin, or create the budget in the Console under Billing → Budgets & alerts.

  4. Create your cargo bay (Cloud Storage)

    gcloud storage buckets create "$BUCKET" \
  --location="$REGION" \
  --uniform-bucket-level-access

# Auto-delete scratch artifacts after 14 days
cat > lifecycle.json <<'EOF'
{"rule": [{"action": {"type": "Delete"}, "condition": {"age": 14}}]}
EOF
gcloud storage buckets update "$BUCKET" --lifecycle-file=lifecycle.json

  5. Create a least-privilege crew account

    Pipelines (Day 2), agents (Day 4) and Cloud Run services (Day 5) run as this service account, not as you. Getting into that habit now pays off in production.

    SA="odyssey-crew@${PROJECT_ID}.iam.gserviceaccount.com"
gcloud iam service-accounts create odyssey-crew --display-name="AI Odyssey crew"

for ROLE in roles/aiplatform.user roles/bigquery.dataEditor roles/bigquery.jobUser \
            roles/storage.objectAdmin roles/logging.logWriter roles/monitoring.metricWriter \
            roles/cloudtrace.agent roles/secretmanager.secretAccessor; do
  gcloud projects add-iam-policy-binding "$PROJECT_ID" \
    --member="serviceAccount:$SA" --role="$ROLE" --condition=None --quiet >/dev/null
done
echo "Crew account ready: $SA"
    Not an Owner? Roles your user needs

    Ask your admin for: roles/aiplatform.user, roles/bigquery.admin (or dataEditor + jobUser + connectionAdmin), roles/storage.admin, roles/serviceusage.serviceUsageConsumer, roles/iam.serviceAccountUser, roles/run.admin, roles/cloudbuild.builds.editor, roles/artifactregistry.admin, roles/modelarmor.admin, roles/notebooks.admin. A sandbox project with Owner saves real time.

  6. Install the 2026 toolchain

    Cloud Shell has Python. Create an isolated environment so versions are reproducible:

    python3 -m venv ~/odyssey && source ~/odyssey/bin/activate
echo 'source ~/odyssey/bin/activate' >> ~/.bashrc

pip install --upgrade pip
pip install \
  google-genai \
  google-cloud-aiplatform \
  google-cloud-bigquery bigframes db-dtypes \
  kfp google-cloud-pipeline-components \
  google-adk \
  xgboost scikit-learn pandas pyarrow \
  openai

pip freeze | grep -Ei "genai|aiplatform|adk|bigframes|kfp"   # note your versions
    Which SDK does what?

    google-genai calls Gemini models. google-cloud-aiplatform drives the platform: training, pipelines, endpoints, evaluation, tuning, RAG Engine and Agent Runtime. google-adk builds agents. bigframes is pandas on BigQuery.

  7. Authenticate your code (ADC)

    # In Cloud Shell, your user creds are already available to libraries.
# On a laptop, run:
gcloud auth application-default login
gcloud auth application-default set-quota-project "$PROJECT_ID"

  8. First contact: talk to Gemini

    cat > first_contact.py <<'EOF'
import os
from google import genai

client = genai.Client(vertexai=True,
                      project=os.environ["PROJECT_ID"],
                      location="global")

resp = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="In exactly two sentences, welcome a new crew member aboard the AI Odyssey, "
             "a week-long voyage through machine learning on Google Cloud. Be delightfully dramatic.",
)
print(resp.text)
print("\ntokens:", resp.usage_metadata.total_token_count)
EOF
python first_contact.py
    A dramatic two-sentence welcome and a token count. If you see it, your project, API, auth and SDK all work. 🎉

  9. Confirm BigQuery and public data access

    bq query --use_legacy_sql=false \
'SELECT COUNT(*) AS orders FROM `bigquery-public-data.thelook_ecommerce.orders`'
    A row count in the hundreds of thousands. This is the dataset that comes back all week.

    Console → Colab Enterprise → Create notebook → Connect (default runtime). In the first cell:

REGION = "us-central1"
BUCKET = f"gs://{PROJECT_ID}-odyssey"

print(client.models.generate_content(model="gemini-3.5-flash-lite",
      contents="Say 'systems nominal' in a space-mission voice.").text)

⚠️ Request GPU quota now

Day 5 serves Gemma 4 on Cloud Run with an NVIDIA L4 GPU. New projects often have a GPU quota of zero, and approvals can take a day or more.

  1. Console → IAM & Admin → Quotas & system limits.
  2. Filter: Total Nvidia L4 GPU allocation, per project per region for Cloud Run Admin API, region us-central1.
  3. Request 1–3 with justification "Training course lab: serving an open model with vLLM".

No quota by Friday? Day 5 includes a Model Garden managed-deployment alternative, and the instructor can demo the Cloud Run path.

📡 Pre-flight quiz

1. Does a Cloud Billing budget stop spending when it hits 100%?

Budgets notify. To cap spend you'd connect budget Pub/Sub notifications to a function that takes action, which is rarely worth it for a class. Clean up daily instead.

2. Which Python package do you use to call Gemini models in 2026?

The unified Google Gen AI SDK (google-genai) works against both the Gemini Developer API and Agent Platform (vertexai=True).

3. Why run pipelines and agents as a dedicated service account?

Least privilege limits blast radius, which matters even more for agents that can call tools (Day 4–5).
